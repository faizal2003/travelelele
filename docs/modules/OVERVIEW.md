# Gambaran Umum Aplikasi Travelelele

Aplikasi ini adalah platform reservasi travel dan paket wisata berbasis Flutter yang terintegrasi dengan Firebase.

## Teknologi Utama
- **Framework**: Flutter (Dart)
- **Database**: Google Cloud Firestore (NoSQL)
- **Autentikasi**: Firebase Auth
- **State Management**: StatefulWidgets & Streams (untuk real-time updates)

## Struktur Folder `lib/`
- `models/`: Definisi objek data.
- `services/`: Komunikasi dengan Firebase.
- `screens/`: Antarmuka pengguna (UI).
- `main.dart`: Entry point aplikasi.
