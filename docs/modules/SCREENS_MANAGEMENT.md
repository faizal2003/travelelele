# Modul Admin & Driver Dashboard

Modul khusus untuk operasional bisnis.

## 1. Admin Dashboard (`admin_dashboard.dart`)
- **Panel Manajemen**: Grid menu untuk mengelola armada, harga, laporan, dan pengguna.
- **Warna Identitas**: Menggunakan tema merah untuk membedakan dengan peran lain.
- **Fitur Logout**: Tersedia di AppBar untuk keamanan sesi.

## 2. Driver Dashboard (`driver_dashboard.dart`)
- **Fitur Utama**:
  - Scan Barcode Tiket (Simulasi validasi tiket).
  - Maps Pengguna.
  - Biodata Penumpang.
  - Akses Profile & Logout.
- **UI**: Tema biru dengan header yang informatif.
