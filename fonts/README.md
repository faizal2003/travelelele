# Plus Jakarta Sans Font Installation

To complete the font setup, you need to download the Plus Jakarta Sans font files and place them in this directory.

## Download Instructions:

1. Visit Google Fonts: https://fonts.google.com/specimen/Plus+Jakarta+Sans
2. Click "Download family" button
3. Extract the downloaded ZIP file
4. Copy the following files from the `static` folder to this `fonts` directory:
   - `PlusJakartaSans-Regular.ttf`
   - `PlusJakartaSans-Medium.ttf`
   - `PlusJakartaSans-SemiBold.ttf`
   - `PlusJakartaSans-Bold.ttf`

## Required Files:
- ✓ fonts/PlusJakartaSans-Regular.ttf
- ✓ fonts/PlusJakartaSans-Medium.ttf (weight: 500)
- ✓ fonts/PlusJakartaSans-SemiBold.ttf (weight: 600)
- ✓ fonts/PlusJakartaSans-Bold.ttf (weight: 700)

## After Adding Fonts:
Run the following command to apply the changes:
```
flutter pub get
```

Then restart your app to see the new font applied throughout the application.
